# Smash Counter — micro:bit v1

**Status:** Active — testing with players  
**Hardware:** BBC micro:bit V2, custom wristband mount  
**Started:** June 2025

## What it does
Counts badminton smash shots using ML gesture detection on the wrist.
Displays count on micro:bit LED display.
Connects to phone via Bluetooth.
